# Sign-Up Form

A sign-up form project built as part of [The Odin Project](https://www.theodinproject.com/) Intermediate HTML and CSS curriculum.

## Preview

![Sign-Up Form Preview](Images/preview.png)

## Features

- Two-column layout built with Flexbox
- Full-bleed background image sidebar
- Six-field form with proper input types and validation
- `:focus` state with blue border and box-shadow on active inputs
- `:invalid` state with red border on password fields
- Responsive-feeling design without JavaScript
- Semantic HTML with properly linked labels and inputs

## Built With

- HTML5
- CSS3 (Flexbox, pseudo-classes)
